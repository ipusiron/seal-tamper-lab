**Day061 - 生成AIで作るセキュリティツール100**


**Seal Tamper Lab** は、物流や情報保護で利用される **封印シール** を題材にした教育ツールです。
シーン、シール、想定する改変、検査方法を選び、確認する痕跡と判断できない点を学びます。実物の検査や物理シミュレーションは行わず、改ざんの有無・検知率・成功率を判定しません。

**物理セキュリティ** は、サイバーセキュリティと同様に重要な領域でありながら、しばしば軽視されがちです。産業スパイ、外国情報機関、内部脅威による **物理的な侵入・改竄** は、デジタル攻撃と組み合わせることで深刻な被害をもたらす可能性があります。本ツールは、そうした **物理的脅威に対する防御意識** を高めることにも寄与します。

## ⚙️ 機能仕様

- シーン3種類、シール5種類、想定する改変6種類、検査6種類をカードで選択
- シーンとシールは単一選択、改変と検査は複数選択
- 選択済みカード・要約・削除ピルを同期し、条件変更時は結果を無効化
- 前段の選択がそろうまで後段を無効化
- 観察候補、検査の前提、判断の限界、条件が一致する教材例を表示
- 確認済みの参考資料を結果の下に展開（外部リンクは別タブ）
- 読み込み失敗の案内と再試行、選択と結果のリセット
- キーボード操作、狭幅表示、動きを減らすOS設定への対応

画像欄は実在するローカル画像が登録されている場合だけ表示します。配布データには観察用画像を登録していないため、結果に画像ボタンは出ません。カードの図柄は説明用の模式表現です。

### 使い方

1. シーンとシールを順に選ぶ。
2. 想定する改変と検査を、それぞれ1つ以上選ぶ。
3. 「確認ポイントと限界」で、各検査の前提を読む。
4. 条件を変えたら、結果を開き直す。「選択と結果を消す」で最初に戻る。

Tabで操作対象に移動します。シーン・シールは矢印キーとHome／Endで選択し、改変・検査はSpace／Enterで切り替えます。ピルの削除でもカードの選択が外れます。

### 結果の読み方

既存4例はシーン・シール・改変の集合が完全に一致する場合に表示します。選択順は考慮しません。検査の選択は、例に記載された検査のうち未選択のものを示すために使います。一致例がない場合も、選んだ検査の観察候補と限界は表示します。

番号なしのシールに対する連番照合、光を通さない対象の透過光観察には制約を表示します。番号・材質などの属性は教材上の想定であり、同種の全製品に当てはまる仕様ではありません。

## 💡 活用シナリオ

このツールならではの使い方

- 前の手順を終えないと次に進めないことを確かめる（手順・前提の授業）：何も選ばずにガイドを出すと、足りないものとして場面・シール・攻撃・検査の4つが順に挙がる。攻撃を選ぶまでは検査の手順（4番目）に進めない。検査には観察する順番と前提があり、途中を飛ばせないことを、手順のロック状態で確かめられる
- 検査には対象の前提があり、合わないと「適用できない」と出ることを確かめる（検査計画の授業）：番号のない透明テープに連番照合を選ぶと、適用できない理由（noSerial）が表示される。段ボール箱に透過光観察を選ぶと、光が通らない対象の理由（opaqueSurface）になる。どんな検査も万能ではなく、対象に前提が合わないと結果でなく「適用外」になることを、組み合わせで確かめられる
- 1つの検査が複数の兆候を見ることを確かめる（検知の設計の授業）：連番照合は、番号の不一致（serial_mismatch）と想定外のロット（unexpected_batch）の2つの兆候を見る。1つの検査が複数の改ざんの跡を拾う一方、1つの跡を複数の検査で裏取りする関係を、検査と兆候の対応で確かめられる

研修や授業では、同じ観察結果にも複数の原因があり得ること、検査に記録や機材の前提があることを考える教材として利用できます。たとえば番号のない透明テープと連番照合を選ぶと、検査を適用できない理由が表示されます。

ワークショップでは、選んだ条件で何を確認し、何が判断できないかを説明し合う形式に利用できます。本ツールは改ざん競技や検出率の採点には対応していません。実物の検査・組織の検査手順・専門的な鑑定に代わるものでもありません。

## 🏷️ 各種シールの詳細特性

### 1. VOIDパターンシール

剥離で文字や模様の表示が変わるラベルです。対象物側に表示が残る型だけでなく、ラベル側に文字が現れる非転着型もあります。[リンテックの製品説明](https://www.lintec.co.jp/topics/newsrelease/171017_a.html)は非転着型の例です。

表示の変化は剥離を考える手掛かりになりますが、表示や残留物がないことから未開封とは判断できません。温度、貼付面、粘着剤の仕様を確認する必要があります。

### 2. ホログラムシール

角度によって模様が変化し、真正な見本との比較に利用できます。ただし、光沢があることだけで真正性や未開封を確認できるわけではありません。耐性は製品の構造と貼付条件によって異なります。

### 3. 紙封緘シール

剥離時に紙の破断や繊維の乱れが生じることがあります。紙や粘着剤の仕様によって挙動は異なり、破損が見当たらないことから貼付履歴を判断することはできません。

### 4. 透明テープ（番号なし）

簡易封印や仮止めを想定した教材です。番号がないため連番照合を適用できません。気泡や歪みは観察候補ですが、貼付時にも生じるため、それだけで再接着とは判断できません。

### 5. 連番入りセキュリティテープ

貼付時の記録と番号を比較できます。ただし、番号の一致は未開封の証明になりません。同ロットであることと同一番号であることも別の条件です。番号以外の外観、在庫、保管・受渡しの記録も確認対象になります。

## ⚔️ 攻撃分類と比較

以下の1〜5は比較を考えるために置いた教材上の仮定です。実測値、製品の評価、発覚確率ではありません。選択しても実際の改ざん処理は行われず、数値は結果の採点にも使いません。

| 想定する改変 | コスト | 時間 | 技術 | 痕跡の目立ちやすさ | 観察候補 |
|---|---:|---:|---:|---:|---|
| 完全除去 | 3 | 4 | 3 | 4 | 下地の荒れ、密度ムラ |
| 同一シール再貼付 | 4 | 2 | 4 | 2 | エッジの段差、接着ムラ |
| 温風で剥がし再接着 | 1 | 2 | 1 | 2 | 気泡、歪み |
| 部分カット | 1 | 3 | 3 | 3 | 段差、光沢差、位置ズレ |
| 溶剤で糊を緩める | 2 | 2 | 2 | 3 | 表面の艶や質感の変化 |
| 下地偽装 | 3 | 4 | 3 | 3 | 基準写真との差、表面の変化 |

痕跡が残ることも検査で見つかることも保証しません。傷や気泡は施工時・輸送中・経年変化でも生じます。実際の改変手順、工具の使用法、対象ごとの成功条件は本ツールの範囲外です。

## 🔍 検査技法とその特徴

画面の観察候補は、実物から検出した結果ではありません。各方法の前提と限界は次のとおりです。

| 検査 | 観察候補 | 前提と限界 |
|---|---|---|
| 斜光観察 | 段差、気泡、歪み | 材質と照明で見え方が変わり、原因は特定できない |
| 基準写真比較 | 位置、角度、質感の差 | 信頼できる貼付直後の写真が必要。撮影条件の違いも差になる |
| 連番照合 | 番号やロットの不一致 | 番号と信頼できる記録が必要。一致しても未開封の証明にならない |
| マクロ観察 | エッジ、接着ムラ、紙繊維 | 倍率や照明に依存し、微細な傷だけでは改ざんと判断できない |
| 透過光観察 | 密度ムラ、剥離跡の候補 | 光が通ることが前提。厚紙や重なり、金属などには適用できない場合がある |
| UV／IR観察 | 材料の蛍光や反射差 | 対応する材料・光源・撮影機材が必要。原因や過去の加熱を特定するものではない |

UVによる蛍光、近赤外照明による反射差、熱画像は区別します。近赤外照明で温度分布を測ることはできません。[FLIRの説明](https://oem.flir.com/en-150/support/support-center/knowledge-base/what-is-the-difference-between-active-ir-and-thermal-imaging/)では、反射光を利用するactive IRと熱画像を区別しています。微細印刷の確認には拡大観察なども必要です。

受け取り時の写真は、その時点からの比較材料にはなりますが、受け取り前に改ざんされていない証明にはなりません。不審な点がある場合は、組織の手順に従って状態を記録し、担当者に確認してください。

## ⚠️ 利用上の注意と判断の限界

封印が存在すること、番号が一致すること、痕跡が見つからないことのいずれも、未開封の証明にはなりません。また、痕跡があっても原因・時期・行為者をこの教材から判断することはできません。

シールを単独で評価せず、製品仕様、貼付時の記録、在庫管理、保管環境、受渡し履歴、異常時の対応手順を含めて検討してください。封印と運用上の限界については、[Johnstonの論文書誌・要旨](https://digital.library.unt.edu/ark:/67531/metadc933842/)も参考になります。リンク先は本ツールの数値や全組み合わせを実証する資料ではありません。

本ツールは教育用であり、実際の侵入・改ざんを実行するための手順書ではありません。実物を調べる場合も所有者の許可と安全な手順に従ってください。

### ブラウザー内の処理

操作中に読み込む教材データは同じ配信元のJSONです。選択はメモリ内だけに保持し、再読み込みで消えます。分析サービスや外部画像は利用しません。参考資料のリンクを開くと、その外部サイトに接続します。

データの文字列はHTMLとして解釈せず表示します。資料は認証情報を含まないHTTPS URLに限定し、画像はローカルassetsの限定した形式のみを扱います。CSPで外部スクリプトやインラインスクリプトを許可しません。ただし、GitHub Pagesのmeta設定だけで他サイトからの埋め込みを拒否できるとは主張しません。

## 📊 データ構造仕様

教材データの正本は[data/db.json](data/db.json)です。

- `scenes`：対象物と表面の説明
- `seals`：種類、特徴、限界、教材上の番号の有無
- `attacks`：想定する改変、観察候補、1〜5の仮定値
- `inspections`：観察方法と対象の分類
- `scenarios`：シーン・シール・改変の集合に対応する既存4例
- `refs`／`images`：任意の参考資料／画像。空の場合はボタンを非表示

`seal-core.js`でIDの重複、項目の型、評価値の範囲、シナリオ内の参照を検査します。不正なデータの場合は操作を開始せず、再試行を案内します。参考資料はURLを検証し、選択条件に含まれる資料をURL単位で重複排除して結果の下に表示します。

## 💻 動作環境・検証

JavaScriptとFetch APIが使えるブラウザーで、HTTP／HTTPS経由で開いてください。ファイルを直接開く`file://`には対応していません。ローカルでは、このフォルダーで次を実行します。

```sh
python -m http.server 8000
```

[http://localhost:8000/](http://localhost:8000/)を開きます。ビルドや依存パッケージの導入は不要です。テストはNode.js 22以上で実行します。

```sh
npm test
```

自動テストは既存4例、前提条件、不正データ、安全なURL・DOM、説明文の限界を対象とします。ブラウザーではChromium・Edge・Firefoxで選択、キーボード、リセット、読み込み失敗からの再試行を確認し、320／390／768／1280pxの幅を確認しています。Safari、スマートフォン実機、スクリーンリーダーの実機確認は行っていません。
